# 🍒 KLONG 6 CAFE (PHP + MySQL)

ระบบเว็บไซต์ร้านคาเฟ่สำหรับสั่งซื้อเค้กและเครื่องดื่มออนไลน์ พัฒนาด้วย PHP และ MySQL มีระบบสมาชิก ระบบสั่งซื้อสินค้า และระบบจัดการร้านค้าสำหรับผู้ดูแลระบบ

## 📌 เทคโนโลยีที่ใช้

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Local Server:** XAMPP
- **Database Management:** phpMyAdmin
- **Version Control:** Git และ GitHub

## 🛠️ วิธีติดตั้ง

1. ติดตั้ง [XAMPP](https://www.apachefriends.org/) ที่รองรับ PHP 8 ขึ้นไป
2. เปิด XAMPP Control Panel แล้วกด Start ที่ **Apache** และ **MySQL**
3. ดาวน์โหลดหรือ Clone โปรเจกต์จาก GitHub แล้วนำโฟลเดอร์ `klong6cafe` ไปไว้ที่

   `C:\xampp\htdocs\klong6cafe`

4. เปิด [phpMyAdmin](http://localhost/phpmyadmin) เพื่อจัดการฐานข้อมูล
5. สร้างฐานข้อมูลชื่อ `klong_6_cafe` หรือนำเข้าไฟล์ SQL ของโปรเจกต์ หากไฟล์ SQL มีคำสั่งสร้างฐานข้อมูลอยู่แล้ว ให้ตรวจสอบชื่อฐานข้อมูลก่อนนำเข้า
6. ตรวจสอบการตั้งค่าการเชื่อมต่อฐานข้อมูลในไฟล์ `conn.php` ให้ตรงกับเครื่องที่ใช้งาน เช่น ชื่อฐานข้อมูล ชื่อผู้ใช้ และรหัสผ่าน MySQL
7. ตรวจสอบว่าโฟลเดอร์สำหรับเก็บรูปสินค้าและสลิปการโอนเงินสามารถเขียนไฟล์ได้

## 🚀 วิธีใช้งาน

หลังจากเปิด Apache และ MySQL แล้ว สามารถเข้าใช้งานเว็บไซต์ผ่านเบราว์เซอร์ได้ดังนี้

- **หน้าร้านค้า:** [http://localhost/klong6cafe/](http://localhost/klong6cafe/)
- **ระบบผู้ดูแล:** เปิดหน้าเข้าสู่ระบบแอดมินตามตำแหน่งไฟล์จริงในโปรเจกต์

## ✨ ฟังก์ชันหลักของระบบ

- ดูสรุปรายการสั่งซื้อและใบเสร็จ

- ตรวจสอบรายการสั่งซื้อ

- ข้อมูลลูกค้า
- ข้อมูลผู้ดูแลระบบ
- ข้อมูลเค้ก
- ข้อมูลเครื่องดื่ม
- ข้อมูลคำสั่งซื้อ
- รายการสินค้าในแต่ละคำสั่งซื้อ
- ข้อมูลการชำระเงินและสลิป
